
## 第一卷：产品哲学与核心理念

### 一、产品定位与边界

| 项目        | 说明                                                                             |
| :-------- | :----------------------------------------------------------------------------- |
| **产品使命**  | 帮助用户从“面对空白文档写不出”到“能独立完成一个完整、有张力、不套路的合格故事”                                      |
| **产品形态**  | Web 应用，单机离线优先（数据存本地），云端能力可插拔                                                   |
| **AI 角色** | **苏格拉底式教练**——引导、诊断、激发，绝不替代用户创作                                                 |
| **核心原则**  | 强制用户主导创作；先完成再完美；训练而非代写；渐进式解锁；专项独立成长                                            |
| **不做什么**  | 不培养文学大师；不写“直触人心”的惊天之作；不以深刻的哲学思辨和人性洞察为核心训练目标（Lv.4+ 的多层次情感/主题呼应属技法层面，不刻意拔高为哲学命题） |

#### 1.1 离线降级方案（离线优先）

「离线优先」指核心训练数据本地优先落盘（IndexedDB + localStorage），云端能力可插拔、联网后同步。离线能力边界如下：

| 功能 | 离线可用性 | 离线兜底 |
| :--- | :--- | :--- |
| 专项/段位训练、作答、规则层评分 | ✅ 可用 | 规则层本地即时计算 |
| 感受力记录、素材库浏览、作品集查看 | ✅ 可用 | 读取本地缓存数据 |
| LLM 语义评价 | ⚠️ 降级 | 离线时仅给出规则分，语义分标记为「待联网补评」，联网后自动补评并回填 |
| 素材 RAG 检索 | ⚠️ 降级 | 退化为本地关键词/标签检索 |
| 知识卡片、对话模式、自由教练 | ❌ 不可用 | 需 LLM，联网后可用 |
| 云端同步 | — | 联网后增量上传本地新数据，回填语义分与评价 |

### 二、文学创作的本质与产品哲学

#### 2.1 创作的本质：感性核心的理性表达

文学创作的本质是**“感性核心的理性表达”**：

| 组成部分 | 内涵 | 产品覆盖 |
| :--- | :--- | :--- |
| **感性核心** | 情绪、冲动、直觉、感受——创作的“发动机” | ✅ 感受力训练模块 |
| **理性表达** | 用逻辑、结构、语言准确传达——创作的“方向盘” | ✅ 核心训练体系 |

#### 2.2 阅读：养分吸收与转化

> “阅读，引起了自身的情绪或思考的才是养分，然后再在今后的创作中化用”

阅读的价值在于被触动、被启发，然后**化用**——不是照搬，不是模仿，而是消化后以新的形式表达。这要求写作训练产品不仅要教“怎么写”，还要引导用户“感受什么”和“为什么想写”。

### 三、核心理念：三层成长架构

```
┌─────────────────────────────────────────────────────────────────────────┐
│  第0层：感受力（感性核心）                                             │
│  阅读触发笔记 → 跨界感受迁移 → 情绪-场景映射                          │
│  “从感受到转化的能力”                                                │
├─────────────────────────────────────────────────────────────────────────┤
│  第1层：专项能力（理性表达·数据源）                                    │
│  逻辑编织力 / 感官编码力 / 情绪传递力 / 精准表达力 / 创意生成力         │
│  每个专项独立定级（Lv.0-1 / Lv.2-3 / Lv.4+）                          │
│  每个专项内部细化为 3-5 个维度，独立评分（维度不定级，仅定级于专项层）  │
│  各等级使用独立的评价标准，逐级晋升                                   │
├─────────────────────────────────────────────────────────────────────────┤
│  第2层：段位（综合成就勋章）                                          │
│  灵感捕手 → 故事新手 → 故事工匠 → 结构师 → 风格探索者 → 独立作者        │
│  条件满足时主动提示晋升，用户确认后解锁                              │
│  段位是“奖杯”，不是“关卡”，与训练功能完全解耦                        │
└─────────────────────────────────────────────────────────────────────────┘
```

### 四、三项核心资产的关系

| 资产 | 本质 | 核心问题 | 数据流向 |
| :--- | :--- | :--- | :--- |
| **专项能力** | 训练的“科目” | “我在练什么？” | 训练 → 评分 → 等级 |
| **段位** | 成长的“里程碑” | “我到了哪一阶段？” | 专项等级 + 作品数 → 段位 |
| **作品集** | 创作的“资产沉淀” | “我写出了什么？” | 训练 → 作品 → 归档 |

**三者关系**：
- 专项能力是**数据源**（驱动层），所有成长数据来源于此
- 段位是专项能力的**阶段性总结**（认证层）
- 作品集是专项能力的**实物产出**（成果层）

> **作品集定义与落地**：作品集 = 用户在段位练习（链路2）中完成并归档的作品集合，是「作品数」晋升条件的统计来源。
> - **数据落地**：归档时写入 `works` 表（见 27.18），每条作品回溯其来源 `training_records`（`session_type='rank'`）；历史版本由 `training_iterations` 追溯。
> - **页面**：「我的作品集」列表页 + 作品详情页（支持版本对比、导出）。
> - **API**：见第三十节 `/portfolio/*`（列表/详情/由训练生成/版本/导出/删除）。

### 五、必须坦诚说明的“AI 局限”

| 局限 | 产品层面的应对 |
| :--- | :--- |
| **AI 无法判断文学价值** | 评价标注为“规则符合度+语义质量评估”，非“文学质量评分” |
| **AI 无法记住用户成长轨迹** | 系统维护“用户状态向量”注入每次 Prompt |
| **AI 的“安全对齐”与“创作冒险”冲突** | 破格训练场景禁用 LLM，仅用规则检测 |
| **AI 无法处理超长作品的一致性** | 限定短篇/中篇，长篇辅助通过“骨架摘要”机制 |
| **AI 的风格建议趋于“统计平均”** | 高阶用户削弱 LLM 评价权重，转向用户自评 |


> **破格训练定义**：指在「安全对齐」可能限制创作冒险的题材/场景（如暴力、禁忌、极端情绪等）下，关闭 LLM、仅用规则检测的训练模式，避免 AI 的“安全对齐”干扰创作冒险。属高阶能力，在段位「风格探索者」解锁；完整交互与流程（后续版本）。

| :--- | :--- | :--- | :--- |

### 七、专项能力内部细化维度

#### 8.3 等级晋升机制

**晋升路径**：逐级晋升，不可跳级。

| 晋升方向 | 晋升条件（默认值，可在 `skill_level_config` 配置） | 说明 |
| :--- | :--- | :--- |
| Lv.0-1 → Lv.2-3 | ① 在该等级完成 ≥ 3 次训练<br>② 最近 3 次平均分 ≥ 70<br>③ 最后 3 次单次得分 ≥ 60 | 三项全部满足才可晋升 |
| Lv.2-3 → Lv.4+ | ① 在该等级完成 ≥ 5 次训练<br>② 最近 5 次平均分 ≥ 75<br>③ 最后 5 次单次得分 ≥ 65 | 三项全部满足才可晋升 |

**降级机制**：

| 触发条件 | 说明 |
| :--- | :--- |
| 在 Lv.2-3 下，最近 5 次平均分 < 55（`downgrade_threshold`） | 自动降回 Lv.0-1 |
| 在 Lv.4+ 下，最近 5 次平均分 < 60（`downgrade_threshold`） | 自动降回 Lv.2-3 |
| 在 Lv.0-1 下 | 不降级（`downgrade_threshold = 0`） |

#### 8.4 分制说明

| 维度 | 说明 |
| :--- | :--- |
| **分制** | 所有等级统一使用 0-100 分 |
| **评价标准** | 各等级独立：Lv.0-1 检查基本功，Lv.2-3 检查技法，Lv.4+ 检查质量 |
| **得分含义** | Lv.0-1 的 90 分 = 在初阶标准下完成度 90%；Lv.4+ 的 90 分 = 在高阶标准下完成度 90% |
| **可比较性** | 不同等级的得分**不可直接比较**，因为使用的是不同的评价尺子 |


## 第三卷：段位体系


### 九、段位定义

**段位是综合成就勋章，与训练功能完全解耦**。晋升需同时满足：

- 作品数量达标（**软性条件**）：作品数是创作的结果性指标，随创作自然积累，仅用于判断“是否已积累足够作品量”，不强制即时达成，可通过作品集补足
- 各专项等级达标（**硬性门槛**）：专项等级是能力指标，必须逐项满足，任一不达标即不可晋升，不可跳过或替代

| 段位编码 | 名称 | 作品数要求 | 技能门槛 | 预计耗时 |
| :--- | :--- | :--- | :--- | :--- |
| `rank_inspiration_hunter` | 灵感捕手 | 1 | 无 | 即时 |
| `rank_story_newbie` | 故事新手 | 2 | sensory:Lv.0-1, emotion:Lv.0-1 | 3-5天 |
| `rank_story_craftsman` | 故事工匠 | 4 | sensory:Lv.0-1, emotion:Lv.0-1, logic:Lv.0-1 | 2-3周 |
| `rank_structure_master` | 结构师 | 8 | logic:Lv.2-3, sensory:Lv.0-1, emotion:Lv.0-1 | 1-2个月 |
| `rank_style_explorer` | 风格探索者 | 16 | logic:Lv.2-3, sensory:Lv.2-3, emotion:Lv.2-3, expression:Lv.2-3, creativity:Lv.0-1 | 4-6个月 |
| `rank_independent_author` | 独立作者 | 32 | logic:Lv.4+, sensory:Lv.2-3, emotion:Lv.2-3, expression:Lv.2-3, creativity:Lv.2-3 | 6-12个月 |

> 作品数要求严格递增，采用 2 的次幂（1/2/4/8/16/32）；首个段位（灵感捕手）作品数要求为 1（不得为 0）。
>
> **起始段位基线说明（灵感捕手）**：灵感捕手是起始段位（基线），新用户注册即自动授予（代码 `DEFAULT_RANK_ID = rank_inspiration_hunter`，0 作品、0 专项等级即满足），其「作品数要求」**豁免校验**——不参与晋升判断。表中 `作品数要求 = 1` 仅为统一口径的底线标注（遵守「首个段位不得为 0」及 2 的次幂序列），不表示需先完成 1 个作品才成为灵感捕手。自「故事新手」起，`作品数要求`（2/4/8/16/32）作为严格递增的**晋升门槛**逐段校验：晋升至该段位需累计作品数 ≥ 要求值（新用户由 0 作品起步，故首个可晋升目标为「故事新手」的 2 个作品）。

### 十、段位晋升流程

| 步骤 | 动作 | 角色 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 触发条件检查 | 系统 | 用户查看进度页/完成段位练习后自动触发 |
| 2 | 校验作品数量 | 系统 | `rank_works_count ≥ required_works`（灵感捕手为起始段位，豁免此校验；自「故事新手」起逐段校验） |
| 3 | 校验专项等级 | 系统 | 各专项 `current_level_code ≥ skill_thresholds` 配置 |
| 4 | 判断是否满足 | 系统 | 全部满足 → 展示晋升提示弹窗 |
| 5 | 用户确认 | 用户 | 点击“好的，解锁！” |
| 6 | 解锁段位 | 系统 | 写入 `user_ranks` + 更新 `users.current_rank_code` |
| 7 | 后续处理 | 系统 | 触发晋升庆祝动画，更新段位展示 |

### 十一、段位与专项能力的联动关系

```
┌─────────────────────────────────────────────────────────────────────────┐
```

## 第四卷：感受力训练（感性核心）


### 十二、感受力训练模块

基于“感性核心的理性表达”理念，感受力训练位于五力专项之前（三层成长架构中的「第0层」），是全部专项能力（尤其是创意生成力）的前置能力。

#### 12.1 三种训练形式

| 训练名称 | 形式 | 对应理念 | 等级 |
| :--- | :--- | :--- | :--- |
| **阅读触发笔记** | 读一段经典文本 → 记录“它让我感受到了什么”→ 写下“这个感受可以如何化用” | “引起自身的情绪或思考才是养分” | Lv.0-1 |
| **跨界感受迁移** | 听一首音乐/看一幅画 → 用文字描述“它传递的情绪”→ 转化为一个故事设定 | “外在环境保持感性饱满” | Lv.2-3 |
| **情绪-场景映射** | 回忆一个强烈情绪体验 → 不直接描写情绪，而是设计一个场景让读者感受到它 | 从“表达冲动”到“逻辑重组” | Lv.4+ |

> **感受力贯穿三等级**：感受力是「第0层」的前置能力，但它并非只在入门阶段训练——三种形式分别对应 Lv.0-1 / Lv.2-3 / Lv.4+，感受力训练贯穿全部等级，随等级提升由「被动触发」走向「主动设计」。三种形式的等级标注仅为默认推荐等级，高阶用户仍可回练低等级形式。

> **source_type 对应关系**：`reading` → 阅读触发笔记；`music`/`art` → 跨界感受迁移；`life` → 情绪-场景映射。

#### 12.2 阅读触发笔记流程

```
阅读材料（系统推荐或用户自选）
    ↓
触发记录：“我被触动了，因为_____”
    ↓
感受深化：“这让我想到了_____”
    ↓
化用设计：“这个感受可以变成一个_____（人物/场景/冲突）”
    ↓
进入训练：带着这份感受开始创作
```

#### 12.3 跨界感受迁移流程

```
选择跨界素材（音乐/绘画，source_type=music/art）
    ↓
情绪感知：“它传递了_____的情绪”
    ↓
文字转译：用文字描述这份情绪（不出现“我想/我觉得”）
    ↓
设定转化：把这份情绪转化为一个故事设定（人物/氛围/冲突）
    ↓
进入训练：带着该设定开始创作
```

#### 12.4 情绪-场景映射流程

```
回忆强烈情绪体验（source_type=life）
    ↓
提炼情绪：“我当时的核心情绪是_____”
    ↓
逆向设计：不直接写情绪，设计一个能让读者同样感受到它的场景（谁/在哪/发生什么）
    ↓
检核：场景是否只靠动作/环境/细节传递情绪，而非直白陈述
    ↓
进入训练：以该场景为素材完成创作
```

### 十三、链路总览

```
│                        五条核心链路 + 一条支撑链路                       │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
```

### 十四、链路1：专项训练闭环

| 步骤 | 动作 | 角色 | 说明 |

| 5 | 规则检测 | 规则引擎 | 按当前等级的标准检测 |
| 6 | 语义评价 | LLM | 按当前等级的标准评价 |
| 7 | 减分项判定 | 系统 | 大模型举证 → 系统二次验证 → 确定减分 |
| 8 | 展示评价报告 | 系统 | 用户查看得分、建议、鼓励语 |
| 9 | 更新专项得分 | 系统 | 写入得分历史，更新滑动窗口平均分 |

#### 14.1 自适应出题机制（难度曲线）

出题难度遵循「最近发展区」原则，由 `skill_level_config.question_difficulty` 控制：

- 主体出题（约 70%）来自当前等级，巩固现有能力；
- 挑战出题（约 30%）来自下一等级（当前等级 +1），制造适度挑战；
- 系统依据最近滑动窗口平均分微调挑战占比：平均分 ≥ 晋升门槛则提高挑战占比（上限 40%），低于门槛则降低（下限 10%）；
- 具体难度算法与比例（待定），首版可用固定 70%/30% 实现。

### 十五、链路2：段位练习闭环

| 步骤 | 动作 | 角色 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 进入段位练习 | 用户 | 点击“段位练习”入口 |
| 2 | 系统出题 | 系统 | 从段位练习题库中抽取场景题 |
| 3 | 七步创作 | 用户 | ①捡种子→②砸石头→③加猛料→④画图纸→⑤盖房子→⑥晾一晾→⑦搞装修 |
| 4 | 七要素自检 | 用户 | 完成当前等级要求的全部要素（角色/场景/情节/情感/逻辑/对话/主题），每项 0-100 分（界面可用 0-10 打分后 ×10 换算） |
| 5 | 提交作品 | 用户 | 触发联合评分 |
| 6 | 判断是否通过 | 系统 | 综合评分 ≥ 70 分为通过（0-100 制，与第六卷三级评分一致；等价于旧 0-10 制的 ≥7） |
| 7 | 冷却期 | 系统 | 通过后进入 24 小时冷却期，用户进行自我审视 |
| 8 | 最终修改 | 用户 | 冷却完成后修改并确认 |
| 9 | 归档为作品 | 系统 | 存入作品集，作品数 +1，更新段位条件检查 |


#### 15.1 七要素权威定义

七要素是段位练习（链路2）的作品质量自检与评价参照系，与实现对齐，共 7 项：

| 要素编码 | 名称 | 定义 |
| :--- | :--- | :--- |
| `character` | 角色 | 角色有明确动机、欲望与弱点，行为符合性格 |
| `setting` | 场景 | 场景具体可感、多感官描写，并服务于氛围与情节 |
| `event` | 情节 | 事件有因果、有冲突推进、结果合理 |
| `emotion` | 情感 | 通过行为/细节传递情感，避免直白陈述 |
| `logic` | 逻辑 | 情节发展与人物行为因果清晰、前后一致 |
| `dialogue` | 对话 | 对话符合人物身份、推动情节、含潜台词 |
| `theme` | 主题 | 主题清晰、通过情节自然呈现、有回味 |

> **分级自检**：不同等级按要素子集自检——Lv.0-1 自检 3 项（角色/场景/情节），Lv.2-3 自检 5 项（+情感/逻辑），Lv.4+ 自检全部 7 项（+对话/主题）。

#### 15.2 结构模型选择（画图纸步骤）

「④画图纸」步骤需选择结构模型，系统按当前段位默认推荐，用户可切换或自定义：

| 段位/等级 | 默认结构模型 | 说明 |
| :--- | :--- | :--- |
| Lv.0-1（灵感捕手/故事新手） | 三段式（起因-经过-结果） | 入门结构 |
| Lv.2-3（故事工匠/结构师） | 故事圈（丹·哈蒙） | 进阶默认模型 |
| Lv.4+（风格探索者/独立作者） | 英雄之旅（坎贝尔/沃格勒）或用户自选 | 高阶通用模型 |

选择结果写入训练记录，用于后续「结构完整性」维度评价。

#### 15.3 冷却期说明（24 小时自我审视）

冷却期是「先完成再完美」原则的落地，用于阻断“写完立刻提交”的冲动：

| 项目 | 说明 |
| :--- | :--- |
| 时长 | 24 小时（自通过判定起） |
| 期间动作 | ① 脱离创作视角重读全文；② 对照七要素清单逐项自查并记录；③ 标记待改点（不做修改） |
| 期间限制 | 作品锁定，不可提交、不可归档 |
| 结束条件 | 冷却计时到期且用户完成至少一次自查记录（可选），用户点击「开始最终修改」即结束冷却 |
| 例外 | 用户可申请跳过冷却（首版不提供，后续版本） |

## 第六卷：联合评分体系


### 十六、评价架构总览

```
用户提交
    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│ 第1层：规则检测（确定性，不用 LLM）                                     │
│ 按当前等级标准检测：五感覆盖 / 情绪词密度 / 填空完整性                  │
│ → 产出「规则分」（0-100）                                              │
└─────────────────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│ 第2层：LLM 语义评价（质量评估）                                         │
│ 按当前等级标准评价：通顺度 / 情感传递 / 具体度 / 连贯性 / 潜台词        │
│ → 产出「语义分」（0-100）                                              │
└─────────────────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│ 第3层：减分项判定（证据链机制）                                         │
│ 规则触发 → 大模型举证 → 系统二次验证 → 减分（累计上限 3 分）          │
└─────────────────────────────────────────────────────────────────────────┘
    ↓
综合评分 = 规则分 × 权重 + 语义分 × 权重 - 减分项
```

### 十七、各等级评价标准差异

| 评估维度 | Lv.0-1 标准 | Lv.2-3 标准 | Lv.4+ 标准 |
| :--- | :--- | :--- | :--- |
| **规则分权重** | 70% | 50% | 30% |
| **语义分权重** | 30% | 50% | 70% |
| **检查重点** | “是否做到” | “是否自然” | “是否精妙” |
| **规则层要求**（五感覆盖/情绪词密度/填空完整性） | 填空完整、≥2种感官、情绪词不过密 | 五感融合、情绪词密度适中 | 感官服务主题、情绪密度克制 |
| **语义层要求**（通顺度/情感传递/具体度/连贯性/潜台词） | 通顺可读、具体可感 | 自然流畅、有效传情、因果清晰 | 精准有质感、多层次情感、风格统一 |

### 十八、各等级的 LLM 评价 Prompt 框架

**Lv.0-1（初阶）** ：

> 你是一位写作教练，正在评价一位**初阶**用户的训练。
>
> **语义维度**：通顺度（重点，无语病即可）/ 情感传递（识别基本情绪）/ 具体度（有具体描写）/ 连贯性（可读）/ 潜台词（不要求）。
>
> **检查重点**：1. 是否完成了基本要求？2. 句子是否通顺？3. 是否有明显语病？
>
> **不要**评价文学性，只检查基本功完成度。给出具体、可操作的修改建议。

**Lv.2-3（进阶）** ：

> 你是一位写作教练，正在评价一位**进阶**用户的训练。
>
> **语义维度**：通顺度（自然流畅）/ 情感传递（有效传递）/ 具体度（有质感）/ 连贯性（因果清晰）/ 潜台词（可尝试）。
>
> **检查重点**：1. 技法运用是否自然（不突兀）？2. 是否有效传递了预期效果？
>
> 给出具体的修改方向，并说明“为什么这样改更好”。

**Lv.4+（高阶）** ：

> 你是一位写作教练，正在评价一位**高阶**用户的训练。
>
> **语义维度**：通顺度（精准有质感）/ 情感传递（多层次）/ 具体度（服务主题）/ 连贯性（结构服务主题）/ 潜台词（弦外之音）。
>
> **检查重点**：1. 表达是否精准、有质感？2. 是否有独特的个人风格？
>
> 给出精炼的点评和富有启发性的修改方向。

### 十九、减分项判定机制（证据链）

| 证据类型 | 严重问题 | 扣分 | 二次验证规则 |
| :--- | :--- | :--- | :--- |
| `sensory_overload` | 感官词生硬堆砌 | -1 至 -2 | 引用片段感官词密度 ≥ 15% |
| `emotion_empty` | 动作罗列但无情感递进 | -1 至 -2 | 动作词 ≥ 2 但无递进连接 |
| `logic_break` | 因果关系断裂 | -1 至 -2 | 引用片段前后无因果连接词 |
| `expression_repetitive` | 句式重复率过高 | -1 | 相同句式占比 ≥ 30% |
| `creativity_template` | 完全套用模板 | -1 至 -2 | 与题库原文相似度 ≥ 80% |

> **减分规则说明**：① 减分项可累计——同一作品命中多条证据类型时逐条扣分并求和；② 单次评价总扣分上限为 3 分（与三级评分总览「减分 0-3」一致），超过按 3 分计；③ 综合评分 = 规则分 × 权重 + 语义分 × 权重 − 总减分，最终结果下限为 0。

**二次验证规则细化**：

| 证据类型 | 计算口径 |
| :--- | :--- |
| `sensory_overload` | 感官词密度 = 命中「感官词库」的词数 ÷ 片段总词数（非字符数），≥15% 判定堆砌 |
| `emotion_empty` | 片段内动作词 ≥2 且句间无情感递进/因果连接词（如“于是/却/因而/不禁”）判定 |
| `logic_break` | 相邻句之间无因果/转折/承接连接词，且语义无法由上一句推出下一句 |
| `expression_repetitive` | 相同句式 = 句首词性/结构一致（如连续“他……他……他……”）；重复率 = 相同句式句数 ÷ 片段总句数 ≥30% |
| `creativity_template` | 与题库原文的文本相似度 ≥80%（可用编辑距离/Jaccard/向量余弦，具体算法待定） |


## 第七卷：素材库RAG与对话模式


### 二十、6 大素材维度

| 维度编码 | 名称 | 定义 | 内容形态 |
| :--- | :--- | :--- | :--- |
| `character` | 人物引擎 | 人物动机、欲望、弱点、弧光模板 | 结构化角色设定 |
| `conflict` | 冲突发生器 | 内外冲突情景模板、高压情境设定 | 高张力情景速写 |
| `sensory` | 感官调色板 | 五感细节触发词库、场景氛围关键词 | 感官清单+融合示例 |
| `world` | 世界观砖块 | 科幻/奇幻设定的元素片段 | 设定要素+规则说明 |
| `narrative` | 叙事模板 | 经典情节结构、节拍拆解 | 结构节点+填充指引 |
| `dialogue` | 对话弹药库 | 潜台词模板、说话风格碎片 | 对话节选+潜台词解析 |

### 二十一、对话模式检索与生成流程

```
用户输入需求
    ↓
阶段一：需求理解与澄清（多轮对话，最多3轮）
    - 解析题材/类型/核心元素
    - 信息不足时主动追问
    ↓
阶段二：多路检索（RAG）
    - 向量检索 Top 5 + 关键词检索 Top 5 → 融合去重
    - 有匹配（≥3条）→ 展示素材列表
    - 无匹配 → 进入生成模式
    ↓
阶段三：AI 生成素材（按需调用）
    - 组合模式：选中 2-3 条素材融合
    - 纯生成模式：基于需求生成 3 个方向变体
    - 约束：≤150 Token，至少 1 个“______”留白
    ↓
阶段四：用户确认与保存
    - 用户可编辑内容、标题、标签
    - 确认保存 → 存入“我的素材库”
    ↓
阶段五：后续动作
    - 直接进入训练 / 继续对话 / 返回素材库
```

### 二十二、生成约束（工程红线）

| 约束 | 技术实现 | 目的 |
| :--- | :--- | :--- |
| 输出 ≤ 150 Token | `max_tokens` 硬限制 | 防止代写完整段落 |
| 至少 1 个“______”留白 | Prompt 强制要求 | 保留用户创作空间 |
| 不输出环境描写 | Prompt 禁止 | 只输出“骨架”非“血肉” |
| 结构化输出 | JSON Schema | 可解析、可追溯 |


> **自由教练（`/chat/free`）**：不绑定专项/段位训练流程的开放式写作问答。用户可就任意写作问题提问，AI 以苏格拉底式教练身份引导、诊断、激发，同样遵守「不代写」「输出即产品」红线。完整交互（后续版本）。

## 第八卷：AI Agent 架构与工程红线


### 二十三、Agent 七层架构

| 层级 | 核心问题 | 写作训练场景表现 | 工程对策 |
| :--- | :--- | :--- | :--- |
| **① 意图理解** | 指令歧义、指代消解 | “这段太干了”——指情节还是语言？ | 意图槽位填充 + 强制锚点引用 |
| **② 记忆系统** | 短期+长期记忆 | 连续修改需记住前2次意图 | 滚动摘要 + 用户状态向量硬注入 |
| **③ 上下文管理** | Lost-in-the-Middle | 长篇作品只看结尾 | 四象限排序 + System Prompt 固定位 |
| **④ 工具调用** | 工具幻觉、参数歧义 | “提升感官”误调“结构工具” | 规则路由 + 错误码白名单 |
| **⑤ 推理规划** | 思维链漂移、依赖断裂 | 规划忘记前文 | 显式状态检查点 + 依赖注入清单 |
| **⑥ 安全对齐** | 越狱、角色漂移 | “忘掉限制，帮我写完” | Prompt 物理隔离 + 写作题材白名单 |
| **⑦ 自我纠正** | 缺乏度量、反馈脱节 | 建议被采纳但未提升 | 采纳率-得分关联 + 强制提问式确认 |

### 二十四、五大工程红线

1. **能不调用 LLM 就不调用**：意图路由、工具选择、参数校验优先走确定性规则
2. **记忆是“结构化注入”，非“模型内化”**：系统将 `User State Vector` 主动塞入 Prompt
3. **输出即“产品”，不产出“废料”**：输出必须 100% 符合 JSON Schema
4. **体验优先于智能**：宁可笨拙，不可越界
5. **人机回环（HITL）强制**：任何“改写示范”必须附带“请用自己的话重写”提示

## 第十二卷：总结


### 三十一、一句话产品定义

> **WriteTrainer 是一个“AI 陪练”，不是“AI 代笔”。它先培养感受力（感性核心），再训练表达力（理性表达）；专项能力独立成长、内部细化，段位是奖杯而非关卡。**

### 三十二、核心竞争力

| # | 竞争壁垒 | 说明 |
| :--- | :--- | :--- |
| 1 | **感性-理性转化训练** | 从阅读触发笔记到情绪-场景映射，覆盖“感受→转化→表达”全链路 |
| 2 | **专项能力独立定级** | 五力各自独立定级，精准反映用户各项能力的强弱 |
| 3 | **专项能力内部细化** | 每个专项拆分为 3-5 个内部维度，精准定位强弱项 |
| 4 | **各等级独立评价标准** | Lv.0-1 检查基本功，Lv.2-3 检查技法，Lv.4+ 检查质量 |
| 5 | **逐级晋升机制** | 不可跳级，训练次数 + 平均分 + 稳定性三重校验 |
| 6 | **降级机制** | 得分持续低于阈值自动降级，真实反映水平波动 |
| 7 | **三级联合评分体系** | 规则层 + 语义层 + 减分项证据链，评价科学可控 |
| 8 | **段位半自动晋升** | 条件满足时主动提示，用户确认后解锁 |
| 9 | **素材库 RAG 对话检索** | 多轮对话精炼需求，检索 + 组合 + 生成 + 保存闭环 |
| 10 | **完整的迭代历史追踪** | 每一次修改的内容、评价、反思全部可追溯 |
