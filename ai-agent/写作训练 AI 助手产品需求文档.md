
## 第一卷：产品哲学与核心理念

### 一、产品定位与边界

| 项目        | 说明                                        |
| :-------- | :---------------------------------------- |
| **产品使命**  | 帮助用户从“面对空白文档写不出”到“能独立完成一个完整、有张力、不套路的合格故事” |
| **产品形态**  | Web 应用，单机离线优先（数据存本地），云端能力可插拔              |
| **AI 角色** | **苏格拉底式教练**——引导、诊断、激发，绝不替代用户创作            |
| **核心原则**  | 强制用户主导创作；先完成再完美；训练而非代写；渐进式解锁；专项独立成长       |
| **不做什么**  | 不培养文学大师；不写“直触人心”的惊天之作；不做深刻的哲学思辨和人性洞察      |

### 二、文学创作的本质与产品哲学

#### 2.1 创作的本质：感性核心的理性表达

文学创作的本质是**“感性核心的理性表达”**：

| 组成部分 | 内涵 | 产品覆盖 |
| :--- | :--- | :--- |
| **感性核心** | 情绪、冲动、直觉、感受——创作的“发动机” | ✅ 感受力训练模块 |
| **理性表达** | 用逻辑、结构、语言准确传达——创作的“方向盘” | ✅ 核心训练体系 |

#### 2.2 阅读：养分吸收与转化

> “阅读，引起了自身的情绪或思考的才是养分，然后再今后的创作中化用”

阅读的价值在于被触动、被启发，然后**化用**——不是照搬，不是模仿，而是消化后以新的形式表达。这要求写作训练产品不仅要教“怎么写”，还要引导用户“感受什么”和“为什么想写”。

### 三、核心理念：三层成长架构

```
┌─────────────────────────────────────────────────────────────────────────┐
│  第0层：感受力（感性核心）                                             │
│  阅读触发笔记 → 跨界感受迁移 → 情绪-场景映射                          │
│  “从感受到转化的能力”                                                │
├─────────────────────────────────────────────────────────────────────────┤
│  第1层：专项能力（理性表达·数据源）                                    │
│  逻辑编织力 / 感官编码力 / 情绪传递力 / 精准表达力 / 创意生成力         │
│  每个专项独立定级（Lv.0-1 / Lv.2-3 / Lv.4+）                          │
│  每个专项内部细化为 3-5 个维度，独立评分                              │
│  各等级使用独立的评价标准，逐级晋升                                   │
├─────────────────────────────────────────────────────────────────────────┤
│  第2层：段位（综合成就勋章）                                          │
│  灵感捕手 → 故事新手 → 故事工匠 → 结构师 → 独立作者                    │
│  条件满足时主动提示晋升，用户确认后解锁                              │
│  段位是“奖杯”，不是“关卡”，与训练功能完全解耦                        │
└─────────────────────────────────────────────────────────────────────────┘
```

### 四、三项核心资产的关系

| 资产 | 本质 | 核心问题 | 数据流向 |
| :--- | :--- | :--- | :--- |
| **专项能力** | 训练的“科目” | “我在练什么？” | 训练 → 评分 → 等级 |
| **段位** | 成长的“里程碑” | “我到了哪一阶段？” | 专项等级 + 作品数 → 段位 |
| **作品集** | 创作的“资产沉淀” | “我写出了什么？” | 训练 → 作品 → 归档 |

**三者关系**：
- 专项能力是**数据源**（驱动层），所有成长数据来源于此
- 段位是专项能力的**阶段性总结**（认证层）
- 作品集是专项能力的**实物产出**（成果层）

### 五、必须坦诚说明的“AI 局限”

| 局限 | 产品层面的应对 |
| :--- | :--- |
| **AI 无法判断文学价值** | 评价标注为“规则符合度+语义质量评估”，非“文学质量评分” |
| **AI 无法记住用户成长轨迹** | 系统维护“用户状态向量”注入每次 Prompt |
| **AI 的“安全对齐”与“创作冒险”冲突** | 破格训练场景禁用 LLM，仅用规则检测 |
| **AI 无法处理超长作品的一致性** | 限定短篇/中篇，长篇辅助通过“骨架摘要”机制 |
| **AI 的风格建议趋于“统计平均”** | 高阶用户削弱 LLM 评价权重，转向用户自评 |


## 第二卷：专项能力体系


### 六、五力专项定义

| 专项编码 | 名称 | 核心定义 | 用户视角副标题 |
| :--- | :--- | :--- | :--- |
| `logic` | 逻辑编织力 | 组织叙事、确保因果清晰 | “让故事‘自然’地流淌” |
| `sensory` | 感官编码力 | 将感知精准转化为文字 | “让读者‘看见’你的世界” |
| `emotion` | 情绪传递力 | 通过外部手段传递内心 | “让读者‘感受’你的内心” |
| `expression` | 精准表达力 | 用精准语言表达丰富意涵 | “让每个字都恰到好处” |
| `creativity` | 创意生成力 | 从无到有产生故事火种 | “让灵感源源不断” |

### 七、专项能力内部细化维度

每个专项能力拆分为 3-5 个内部维度，独立评分，精准反映用户在该专项上的具体强弱项。

#### 7.1 逻辑编织力（`logic`）

| 内部维度 | 编码 | 说明 |
| :--- | :--- | :--- |
| 事件因果链 | `logic_causality` | 事件之间是否有“因为…所以…”的连接 |
| 结构完整性 | `logic_structure` | 故事是否有完整的起承转合 |
| 起承转合掌握度 | `logic_sequence` | 四个段落是否清晰可辨、过渡自然 |
| 伏笔回收能力 | `logic_foreshadow` | 是否能够埋设并回收伏笔 |

#### 7.2 感官编码力（`sensory`）

| 内部维度 | 编码 | 说明 |
| :--- | :--- | :--- |
| 视觉描写能力 | `sensory_visual` | 能否让读者“看见”场景 |
| 听觉描写能力 | `sensory_auditory` | 能否让读者“听见”声音 |
| 触觉描写能力 | `sensory_tactile` | 能否让读者“触摸”到质感 |
| 嗅觉/味觉描写能力 | `sensory_olfactory` | 能否让读者“闻到”气味 |
| 多感官融合能力 | `sensory_blend` | 能否让多种感官自然交织 |

#### 7.3 情绪传递力（`emotion`）

| 内部维度 | 编码 | 说明 |
| :--- | :--- | :--- |
| 情绪识别与表达 | `emotion_identify` | 能否识别并传达基本情绪 |
| 行为折射能力 | `emotion_actions` | 能否用动作折射内心 |
| 环境烘托能力 | `emotion_atmosphere` | 能否用环境映照情绪 |
| 潜台词运用能力 | `emotion_subtext` | 能否在对话中藏进“未尽之言” |
| 情绪层次设计 | `emotion_layers` | 能否传递复杂情绪和情绪变化 |

#### 7.4 精准表达力（`expression`）

| 内部维度 | 编码 | 说明 |
| :--- | :--- | :--- |
| 语言通顺度 | `expression_fluency` | 句子是否通顺、无语病 |
| 冗余控制能力 | `expression_conciseness` | 能否删减冗余、精准表达 |
| 句式多样性 | `expression_variety` | 句式是否丰富、不单调 |
| 繁简控制能力 | `expression_rhythm` | 能否在繁复与简洁间自如切换 |

#### 7.5 创意生成力（`creativity`）

| 内部维度 | 编码 | 说明 |
| :--- | :--- | :--- |
| 观察力 | `creativity_observation` | 能否从日常中发现创作素材 |
| 联想力 | `creativity_association` | 能否将不同元素关联起来 |
| 置换能力 | `creativity_displacement` | 能否将已有结构置换到新场景 |
| 组合创意能力 | `creativity_combination` | 能否将多个创意元素融合为新的故事 |

### 八、专项等级体系

#### 8.1 等级与评价标准的关系

**核心原则：每个等级有独立的评价标准，各等级得分不可直接比较。**

| 维度 | Lv.0-1（初阶） | Lv.2-3（进阶） | Lv.4+（高阶） |
| :--- | :--- | :--- | :--- |
| **评价侧重点** | “是否做到” | “是否自然” | “是否精妙” |
| **规则层权重** | 70% | 50% | 30% |
| **语义层权重** | 30% | 50% | 70% |
| **检查重点** | 填空完成、基础五感覆盖、通顺度 | 五感融合、行为折射情绪、结构完整 | 主题呼应、多层次情感、风格统一 |
| **字数上限** | 300-500 字 | 500-3000 字 | 3000-10000 字 |

#### 8.2 各等级的内部维度水平描述

| 专项能力 | 内部维度 | Lv.0-1 目标 | Lv.2-3 目标 | Lv.4+ 目标 |
| :--- | :--- | :--- | :--- | :--- |

| | 结构完整性 | 能有头有尾 | 起承转合清晰 | 结构服务于主题 |
| | 起承转合掌握度 | 能区分四个部分 | 过渡自然流畅 | 转折有冲击力 |
| | 伏笔回收能力 | — | 能埋设简单伏笔 | 能设计多层伏笔并回收 |
| **感官编码力** | 视觉描写能力 | 能用视觉描写场景 | 视觉描写有质感 | 视觉成为情绪载体 |
| | 听觉描写能力 | 能用听觉辅助场景 | 听觉有氛围感 | 听觉传递隐喻 |
| | 触觉描写能力 | — | 能用触觉增加真实感 | 触觉与情绪联动 |
| | 嗅觉/味觉描写能力 | — | 能运用嗅觉/味觉 | 嗅觉/味觉成为记忆锚点 |
| | 多感官融合能力 | — | 能融合 2-3 种感官 | 五感自然交织、服务主题 |
| **情绪传递力** | 情绪识别与表达 | 能识别基本情绪 | 能识别复杂情绪 | 能识别微妙情绪变化 |
| | 行为折射能力 | 能用动作传递情绪 | 行为折射自然 | 行为成为“内心发声器” |

| | 潜台词运用能力 | — | — | 对话有弦外之音 |
| | 情绪层次设计 | — | 能表达 2 层情绪 | 能表达多层次情绪变化 |
| **精准表达力** | 语言通顺度 | 无语病 | 语句流畅 | 语言精准有质感 |

| | 组合创意能力 | — | 能组合 2 个创意元素 | 能组合多个创意元素 |

#### 8.3 等级晋升机制

**晋升路径**：逐级晋升，不可跳级。

| 晋升方向 | 晋升条件 | 说明 |
| :--- | :--- | :--- |
| Lv.0-1 → Lv.2-3 | ① 在该等级完成 ≥ N 次训练<br>② 最近 N 次平均分 ≥ 晋升门槛<br>③ 最后若干次单次得分 ≥ 稳定性最低分 | 三项全部满足才可晋升 |
| Lv.2-3 → Lv.4+ | ① 在该等级完成 ≥ N 次训练<br>② 最近 N 次平均分 ≥ 晋升门槛<br>③ 最后若干次单次得分 ≥ 稳定性最低分 | 三项全部满足才可晋升 |

**降级机制**：

| 触发条件 | 说明 |
| :--- | :--- |
| 在 Lv.2-3 下，最近 N 次平均分低于降级阈值 | 自动降回 Lv.0-1 |
| 在 Lv.4+ 下，最近 N 次平均分低于降级阈值 | 自动降回 Lv.2-3 |

#### 8.4 分制说明

| 维度 | 说明 |
| :--- | :--- |
| **分制** | 所有等级统一使用 0-100 分 |
| **评价标准** | 各等级独立：Lv.0-1 检查基本功，Lv.2-3 检查技法，Lv.4+ 检查质量 |
| **得分含义** | Lv.0-1 的 90 分 = 在初阶标准下完成度 90%；Lv.4+ 的 90 分 = 在高阶标准下完成度 90% |
| **可比较性** | 不同等级的得分**不可直接比较**，因为使用的是不同的评价尺子 |


## 第三卷：段位体系


### 九、段位定义

**段位是综合成就勋章，与训练功能完全解耦**。晋升需同时满足：

- 作品数量达标（软性条件）
- 各专项等级达标（硬性门槛）

| 段位编码 | 名称 | 作品数要求 | 技能门槛 | 预计耗时 |
| :--- | :--- | :--- | :--- | :--- |
| `rank_inspiration_hunter` | 灵感捕手 | 0 | 无 | 即时 |
| `rank_story_newbie` | 故事新手 | 1 | sensory:Lv.0-1, emotion:Lv.0-1 | 3-5天 |
| `rank_story_craftsman` | 故事工匠 | 3 | sensory:Lv.0-1, emotion:Lv.0-1, logic:Lv.0-1 | 2-3周 |
| `rank_structure_master` | 结构师 | 2 | logic:Lv.2-3, sensory:Lv.0-1, emotion:Lv.0-1 | 1-2个月 |
| `rank_style_explorer` | 风格探索者 | 5 | logic:Lv.2-3, sensory:Lv.2-3, emotion:Lv.2-3, expression:Lv.2-3, creativity:Lv.0-1 | 4-6个月 |
| `rank_independent_author` | 独立作者 | 8 | logic:Lv.4+, sensory:Lv.2-3, emotion:Lv.2-3, expression:Lv.2-3, creativity:Lv.2-3 | 6-12个月 |

### 十、段位晋升流程

| 步骤 | 动作 | 角色 | 说明 |
| :--- | :--- | :--- | :--- |
| 1 | 触发条件检查 | 系统 | 用户查看进度页/完成段位练习后自动触发 |
| 2 | 校验作品数量 | 系统 | `rank_works_count ≥ required_works` |
| 3 | 校验专项等级 | 系统 | 各专项 `current_level_code ≥ skill_thresholds` 配置 |
| 4 | 判断是否满足 | 系统 | 全部满足 → 展示晋升提示弹窗 |
| 5 | 用户确认 | 用户 | 点击“好的，解锁！” |
| 6 | 解锁段位 | 系统 | 写入 `user_ranks` + 更新 `users.current_rank_code` |
| 7 | 后续处理 | 系统 | 触发晋升庆祝动画，更新段位展示 |

### 十一、段位与专项能力的联动关系

```

│                    段位与专项能力的联动                                │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  用户完成训练 → 专项得分更新 → 专项等级可能变化                         │
│                              ↓                                         │

```


## 第四卷：感受力训练（感性核心）


### 十二、感受力训练模块

基于“感性核心的理性表达”理念，新增感受力训练作为创意生成力的前置能力。

#### 12.1 三种训练形式

| 训练名称 | 形式 | 对应理念 | 等级 |
| :--- | :--- | :--- | :--- |
| **阅读触发笔记** | 读一段经典文本 → 记录“它让我感受到了什么”→ 写下“这个感受可以如何化用” | “引起自身的情绪或思考才是养分” | Lv.0-1 |
| **跨界感受迁移** | 听一首音乐/看一幅画 → 用文字描述“它传递的情绪”→ 转化为一个故事设定 | “外在环境保持感性饱满” | Lv.2-3 |
| **情绪-场景映射** | 回忆一个强烈情绪体验 → 不直接描写情绪，而是设计一个场景让读者感受到它 | 从“表达冲动”到“逻辑重组” | Lv.4+ |

#### 12.2 阅读触发笔记流程

```
阅读材料（系统推荐或用户自选）
    ↓
触发记录：“我被触动了，因为_____”
    ↓
感受深化：“这让我想到了_____”
    ↓
化用设计：“这个感受可以变成一个_____（人物/场景/冲突）”
    ↓
进入训练：带着这份感受开始创作
```


## 第五卷：核心业务链路


### 十三、链路总览

```
┌─────────────────────────────────────────────────────────────────────────┐
│                        五条核心链路 + 一条支撑链路                       │
├─────────────────────────────────────────────────────────────────────────┤
│                                                                         │
│  链路0：感受力训练闭环（新增·前置引擎）                                 │
│  阅读/体验 → 触发记录 → 感受深化 → 化用设计 → 进入创作                 │
│                                                                         │
│  链路1：专项训练闭环（能力成长引擎·频率最高）                            │
│  出题 → 作答 → 联合评分 → 更新得分 → 检查晋升/降级                     │
│                                                                         │
│  链路2：段位练习闭环（作品产出引擎）                                    │
│  出题 → 七步创作 → 七要素自检 → 联合评分 → 冷却 → 修改 → 归档为作品     │
│                                                                         │
│  链路3：段位晋升链路（成就认证）                                        │
│  条件检查 → 满足条件 → 主动提示用户 → 用户确认 → 解锁段位              │
│                                                                         │
│  链路4：修改迭代链路（打磨闭环）                                        │

│                                                                         │
│  支撑链路：素材与急救（辅助引擎）                                       │
│  对话检索 → 组合生成 → 卡文推演 → 辅助创作                             │
└─────────────────────────────────────────────────────────────────────────┘
```

### 十四、链路1：专项训练闭环

| 步骤 | 动作 | 角色 | 说明 |
| :--- | :--- | :--- | :--- |

## 第六卷：联合评分体系


### 十六、评价架构总览

```
用户提交
    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│ 第1层：规则检测（确定性，不用 LLM）                                     │
│ 按当前等级标准检测：五感覆盖 / 情绪词密度 / 填空完整性 / 通顺度         │
│ → 产出「规则分」（0-100）                                              │
└─────────────────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│ 第2层：LLM 语义评价（质量评估）                                         │
│ 按当前等级标准评价：流畅度 / 情感传递 / 具体度 / 连贯性 / 潜台词        │
│ → 产出「语义分」（0-100）                                              │
└─────────────────────────────────────────────────────────────────────────┘
    ↓
┌─────────────────────────────────────────────────────────────────────────┐
│ 第3层：减分项判定（证据链机制）                                         │
│ 规则触发 → 大模型举证 → 系统二次验证 → 确定减分（0-3）                │
└─────────────────────────────────────────────────────────────────────────┘
    ↓
综合评分 = 规则分 × 权重 + 语义分 × 权重 - 减分项
```

### 十七、各等级评价标准差异

| 评估维度 | Lv.0-1 标准 | Lv.2-3 标准 | Lv.4+ 标准 |
| :--- | :--- | :--- | :--- |
| **规则分权重** | 70% | 50% | 30% |
| **语义分权重** | 30% | 50% | 70% |
| **检查重点** | “是否做到” | “是否自然” | “是否精妙” |
| **规则层要求** | 填空完整、≥2种感官、情绪词不过密 | 五感融合、行为折射情绪 | 感官与主题呼应、情感多层次 |
| **语义层要求** | 通顺可读 | 自然流畅、传递情绪 | 精准深刻、风格统一 |

### 十八、各等级的 LLM 评价 Prompt 框架

**Lv.0-1（初阶）** ：

> 你是一位写作教练，正在评价一位**初阶**用户的训练。
>
> **检查重点**：1. 是否完成了基本要求？2. 句子是否通顺？3. 是否有明显语病？
>
> **不要**评价文学性，只检查基本功完成度。给出具体、可操作的修改建议。

**Lv.2-3（进阶）** ：

> 你是一位写作教练，正在评价一位**进阶**用户的训练。
>
> **检查重点**：1. 技法运用是否自然（不突兀）？2. 是否有效传递了预期效果？
>
> 给出具体的修改方向，并说明“为什么这样改更好”。

**Lv.4+（高阶）** ：

> 你是一位写作教练，正在评价一位**高阶**用户的训练。
>
> **检查重点**：1. 表达是否精准、有质感？2. 是否有独特的个人风格？
>
> 给出精炼的点评和富有启发性的修改方向。

### 十九、减分项判定机制（证据链）

| 证据类型 | 严重问题 | 扣分 | 二次验证规则 |
| :--- | :--- | :--- | :--- |
| `sensory_overload` | 感官词生硬堆砌 | -1 至 -2 | 引用片段感官词密度 ≥ 15% |
| `emotion_empty` | 动作罗列但无情感递进 | -1 至 -2 | 动作词 ≥ 2 但无递进连接 |
| `logic_break` | 因果关系断裂 | -1 至 -2 | 引用片段前后无因果连接词 |
| `expression_repetitive` | 句式重复率过高 | -1 | 相同句式占比 ≥ 30% |
| `creativity_template` | 完全套用模板 | -1 至 -2 | 与题库原文相似度 ≥ 80% |

### 二十、6 大素材维度

| 维度编码 | 名称 | 定义 | 内容形态 |
| :--- | :--- | :--- | :--- |

### 二十一、对话模式检索与生成流程

```
用户输入需求
    ↓
阶段一：需求理解与澄清（多轮对话，最多3轮）
    - 解析题材/类型/核心元素
    - 信息不足时主动追问
    ↓
阶段二：多路检索（RAG）
    - 向量检索 Top 5 + 关键词检索 Top 5 → 融合去重
    - 有匹配（≥3条）→ 展示素材列表
    - 无匹配 → 进入生成模式
    ↓
阶段三：AI 生成素材（按需调用）
    - 组合模式：选中 2-3 条素材融合
    - 纯生成模式：基于需求生成 3 个方向变体
    - 约束：≤150 Token，至少 1 个“______”留白
    ↓
阶段四：用户确认与保存
    - 用户可编辑内容、标题、标签
    - 确认保存 → 存入“我的素材库”
    ↓
阶段五：后续动作
    - 直接进入训练 / 继续对话 / 返回素材库
```

### 二十二、生成约束（工程红线）

| 约束 | 技术实现 | 目的 |
| :--- | :--- | :--- |
| 输出 ≤ 150 Token | `max_tokens` 硬限制 | 防止代写完整段落 |
| 至少 1 个“______”留白 | Prompt 强制要求 | 保留用户创作空间 |
| 不输出环境描写 | Prompt 禁止 | 只输出“骨架”非“血肉” |
| 结构化输出 | JSON Schema | 可解析、可追溯 |


## 第八卷：AI Agent 架构与工程红线


### 二十三、Agent 七层架构

| 层级 | 核心问题 | 写作训练场景表现 | 工程对策 |
| :--- | :--- | :--- | :--- |
| **① 意图理解** | 指令歧义、指代消解 | “这段太干了”——指情节还是语言？ | 意图槽位填充 + 强制锚点引用 |
| **② 记忆系统** | 短期+长期记忆 | 连续修改需记住前2次意图 | 滚动摘要 + 用户状态向量硬注入 |
| **③ 上下文管理** | Lost-in-the-Middle | 长篇作品只看结尾 | 四象限排序 + System Prompt 固定位 |
| **④ 工具调用** | 工具幻觉、参数歧义 | “提升感官”误调“结构工具” | 规则路由 + 错误码白名单 |
| **⑤ 推理规划** | 思维链漂移、依赖断裂 | 规划忘记前文 | 显式状态检查点 + 依赖注入清单 |
| **⑥ 安全对齐** | 越狱、角色漂移 | “忘掉限制，帮我写完” | Prompt 物理隔离 + 写作题材白名单 |
| **⑦ 自我纠正** | 缺乏度量、反馈脱节 | 建议被采纳但未提升 | 采纳率-得分关联 + 强制提问式确认 |

### 二十四、五大工程红线

1. **能不调用 LLM 就不调用**：意图路由、工具选择、参数校验优先走确定性规则
2. **记忆是“结构化注入”，非“模型内化”**：系统将 `User State Vector` 主动塞入 Prompt
3. **输出即“产品”，不产出“废料”**：输出必须 100% 符合 JSON Schema
4. **体验优先于智能**：宁可笨拙，不可越界
5. **人机回环（HITL）强制**：任何“改写示范”必须附带“请用自己的话重写”提示

## 第十二卷：总结


### 三十一、一句话产品定义

> **WriteTrainer 是一个“AI 陪练”，不是“AI 代笔”。它先培养感受力（感性核心），再训练表达力（理性表达）；专项能力独立成长、内部细化，段位是奖杯而非关卡。**

### 三十二、核心竞争力

| # | 竞争壁垒 | 说明 |
| :--- | :--- | :--- |
| 1 | **感性-理性转化训练** | 从阅读触发笔记到情绪-场景映射，覆盖“感受→转化→表达”全链路 |
| 2 | **专项能力独立定级** | 五力各自独立定级，精准反映用户各项能力的强弱 |
| 3 | **专项能力内部细化** | 每个专项拆分为 3-5 个内部维度，精准定位强弱项 |
| 4 | **各等级独立评价标准** | Lv.0-1 检查基本功，Lv.2-3 检查技法，Lv.4+ 检查质量 |
| 5 | **逐级晋升机制** | 不可跳级，训练次数 + 平均分 + 稳定性三重校验 |
| 6 | **降级机制** | 得分持续低于阈值自动降级，真实反映水平波动 |
| 7 | **三级联合评分体系** | 规则层 + 语义层 + 减分项证据链，评价科学可控 |
| 8 | **段位半自动晋升** | 条件满足时主动提示，用户确认后解锁 |
| 9 | **素材库 RAG 对话检索** | 多轮对话精炼需求，检索 + 组合 + 生成 + 保存闭环 |
| 10 | **完整的迭代历史追踪** | 每一次修改的内容、评价、反思全部可追溯 |
