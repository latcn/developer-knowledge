## 第一卷：产品战略与定位

### 一、文档说明

本文档为“写作训练 AI 助手”产品的完整需求说明书，整合了此前全部产品讨论成果。文档以“**从不会写到能写出合格作品**”为产品使命，涵盖产品定位、用户场景、训练体系、评价机制、知识库、数据飞轮、商业模式等完整模块。

### 二、产品背景

现有 AI 写作工具普遍聚焦于**直接生成内容**，通过 AI 续写、润色等功能，导致用户丧失自主构思、逻辑推演和文风打磨能力。市场存在以下未满足需求：

- **教育刚需**：高校写作课、职业培训中，学员缺乏实时、个性化反馈。
- **能力断层**：初学者依赖 AI 填充内容，长期使用者细节描写能力退化。
- **认知转变**：越来越多写作者意识到“能写出10万字”≠“掌握写作能力”，对“能力训练”需求上升。

与此同时，实证研究已证明 AI 能有效训练写作能力（效应量 g=0.80，2026 年元分析）。产品机会明确：开发以“训练写作能力”为核心目标的 AI 助手，填补能力培养空白。

### 三、产品定位

本产品是帮助用户**从不会写作到能写出合格作品**的 AI 训练助手。

| 对比维度 | 传统 AI 写作工具 | 本产品（写作训练 AI 助手） |
| :--- | :--- | :--- |
| 核心目标 | 快速产出内容 | 让用户能写出合格作品 |
| AI 角色 | 代笔者/润色者 | 教练 + 陪练 |
| 用户参与度 | 低（一键生成） | 高（全程手动创作与修改） |
| 评价方式 | 结果导向（内容质量） | 过程与能力导向（多维技能评分） |
| 长期价值 | 内容资产 | 能力资产 + 个人成长数据 |
| 激励机制 | 字数/完成度 | 能力提升 + 技能树点亮 |

### 四、核心理念

1. **强制用户主导创作**：AI 严禁替代用户完成核心创作，仅扮演引导者、诊断者和反馈者。
2. **先完成，再完美**：Lv.0-1 阶段鼓励尝试具体化表达，降低心理门槛，让用户先“写出来”。
3. **训练而非代写**：产品的核心目标是提升用户能力而非产出内容。
4. **零件训练 + 整车组装**：既有专项技能拆解训练，也有完整作品的整合创作。

### 五、产品边界声明

**本产品“教什么”：**
- 如何把脑子里的故事变成文字
- 如何写出能让读者看明白的场景、人物和对话
- 如何构建一个完整、通顺、有吸引力的故事
- 如何识别和修正自己作品中的常见问题

**本产品“不教什么”：**
- 如何成为文学大师
- 如何写出“直触人心”的惊天之作
- 如何进行深刻的哲学思辨和人性洞察

**核心原则**：明确边界，只做 AI 擅长且有价值的“技能训练”部分。“思想深度”和“艺术性”不是产品能够直接训练的——这些来自用户自己的人生体验和阅读积累。产品帮助用户把已有的思想用文字表达出来，而非赋予用户思想。

### 六、合格作品的标准（七要素）

在开始训练之前，用户需要知道“合格作品”长什么样。产品中应明确定义“合格作品”的七个维度，让用户对训练目标有清晰认知。

**小说七个关键成功因素**：

| 要素 | 定义 | 合格标准（Lv.0-3目标） | 进阶标准（Lv.4-6目标） |
| :--- | :--- | :--- | :--- |
| **情节** | 事件的发展与转折 | 有明确的因果关系链，读者能复述“发生了什么” | 紧凑有悬念，高潮有冲击力 |
| **结构** | 起承转合的布局 | 有开端-发展-结尾的完整框架 | 节奏张弛有度，符合叙事弧线 |
| **人物** | 立体有动机的角色 | 主角有明确目标和基本动机 | 次要角色立体，主角有成长弧光 |
| **场景** | 细节生动的环境 | 读者能“看见”场景的基本画面 | 多感官融合，氛围与情绪呼应 |
| **对话** | 推动情节或揭示性格 | 对话能传递信息、区分人物 | 对话自然、有潜台词、推动冲突 |
| **风格** | 语言特色和叙事视角 | 语言通顺、无语病 | 有辨识度、叙事视角统一 |
| **意义（主题）** | 核心思想或隐喻 | 故事有基本意图（想表达什么） | 主题有深度，引发思考 |

产品中的每个训练任务都应让用户感知到“我在提升哪个要素”，整合训练时则要求用户综合运用全部七要素。

## 第三卷：训练模式与体系


### 九、三种训练模式

#### 模式一：稿件分析与提升训练

- **适用场景**：用户已有初稿（≥500 字），想针对性提升
- **核心流程**：上传稿件 → 智能诊断 → 生成诊断报告 + 专项处方 → 推送弱点狙击任务 → 反复打磨 → 进度追踪

#### 模式二：专项技能刻意练习

- **适用场景**：用户想专项攻克某项写作技能
- **核心流程**：依据“最近发展区”理论，将技能拆解为递进式训练阶段 → 每个阶段多个主题 → 出题→创作→评价→修改→再评价闭环

#### 模式三：结构化临摹训练

- **定位**：穿插于前两者之间的“内化环节”
- **三阶段**：精准观察（强制解构） → 限定条件临摹（三选一模式） → 反向拆解（临摹回溯）

### 十、五力专项训练体系

写作能力拆解为五项可训练的技能，构成完整的训练框架：

| 专项能力 | 核心定义 | 对应《这样写出好故事》分册 |
| :--- | :--- | :--- |
| **感官编码力** | 将对外部世界的感知（视/听/触/嗅/味）精准转化为文字的能力 | 《描写与背景》 |
| **情绪传递力** | 通过行为、环境、对话等外部手段，让读者感受到角色内心情绪的能力 | 《人物对话》 |
| **逻辑编织力** | 组织思想、构建清晰叙事脉络、确保因果链清晰稳固的能力 | 《情节与结构》 |
| **精准表达力** | 用最精准的语言（而非简单删减形容词）表达丰富意涵的能力 | 贯穿三册的核心理念 |
| **创意生成力** | 从无到有构思故事的能力——包括灵感激发、人物设计、冲突构建、故事大纲等 | 《情节与结构》创意部分 |

#### 10.1 创意生成力的核心教学方法：“LOCK + 八步故事法”

创意生成力专项以“LOCK机制 + 八步故事法”为核心教学方法，形成从战略核心到战术蓝图再到具体执行的完整训练路径。

**LOCK机制（故事的战略核心）** ：

| 要素 | 含义 | 训练要点 |
| :--- | :--- | :--- |
| **L（Lead，主角）** | 故事是关于谁的 | 主角需具备吸引力，有复杂性或独特特质 |
| **O（Objective，目标）** | 主角想要什么 | 目标需明确、有紧迫性和重要性 |
| **C（Confrontation，冲突）** | 什么在阻止主角 | 通过内外冲突制造障碍，增强张力 |
| **K（Knockout，冲击结局）** | 最终结果是什么 | 结局需有力，解决冲突并给读者情感冲击 |

LOCK机制的作用：确保故事有核心驱动力、冲突和情感共鸣，避免松散。

**八步故事法（故事的战术蓝图）** ：

丹·哈蒙的“八步故事法”是一个循环式的叙事框架，用于构建角色驱动的故事。它将经典英雄之旅理论简化为8个清晰步骤，强调角色的内在成长与外部冲突的结合：

1. 角色处于舒适区
2. 但 ta 渴望某物
3. 进入陌生环境
4. 适应新环境
5. 得到所求之物
6. 为此付出代价
7. 返回原环境
8. 角色已发生改变

**LOCK驱动八步法的映射关系**：

| 八步故事法 | 如何体现LOCK机制 |
| :--- | :--- |
| **1. 角色处于舒适区** | 引入**主角（Lead）** ，展示他的日常状态和性格底色。 |
| **2. 但 ta 渴望某物** | 主角的内心**目标（Objective）** 开始浮现——他想要某样东西。 |
| **3. 进入陌生环境** | 外部**冲突（Confrontation）** 迫使主角离开舒适区，进入新环境。 |
| **4. 适应新环境** | 主角开始学习新规则，对**目标**的追求从被动转为主动。 |
| **5. 得到所求之物** | 主角获得了最初想要的东西——但通常以他未曾预料的方式。 |
| **6. 为此付出代价** | **冲突**达到顶峰，主角陷入“至暗时刻”，付出沉重代价。 |
| **7. 返回原环境** | 主角带着经历返回熟悉的原环境，但一切已不再相同。 |
| **8. 角色已发生改变** | **冲击结局（Knockout）** 在此沉淀——展示主角的根本性变化。 |

**LOCK + 八步法 + 七要素的协同关系**：

```
LOCK机制（战略核心）→ 定义“故事是什么”
         ↓
八步故事法（战术蓝图）→ 规划“故事怎么讲”
         ↓
七要素（质量标准）→ 衡量“故事好不好”
```

三者构成从构思到结构再到质量的完整训练链条。

#### 10.2 创意生成力各阶段训练结构

| 阶段 | 训练目标 | 训练任务 | AI 角色 |
| :--- | :--- | :--- | :--- |
| **Lv.0-1：四要素+LOCK确立** | 能清晰地回答故事核心问题 | 填写“故事核心卡”（含LOCK四要素） | 创意催化剂——通过提问帮助完善 |
| **Lv.2-3：八步法大纲** | 能将四要素展开为完整大纲 | 根据LOCK完成八步法大纲（舒适区→渴望→进入陌生环境→适应→得到所求→付出代价→返回原环境→角色改变） | 结构工程师——检查八步完整性和节奏 |
| **Lv.4-5：七要素综合** | 能用七要素标准审视并完善作品 | 从七要素维度对作品进行自我评估和改进 | 质量检查员——对照七要素提供反馈 |

### 十一、各专项训练目标总览

| 专项 | Lv.0-1（见山是山） | Lv.2-3（见山不是山） | Lv.4-5（见山不是山-后期） | Lv.6+（见山还是山） |
| :--- | :--- | :--- | :--- | :--- |
| **感官编码力** | 让读者能“看见”场景（五感轮盘基础） | 掌握感官描写的多种技法 | 感官细节与情绪自然融合 | 风格化感官表达 |
| **情绪传递力** | 让读者识别基本情绪（尝试用行为支撑） | 掌握“行为折射情绪”技法 | 多维度协同传递情绪 | 直达人心的情绪传递 |
| **逻辑编织力** | 讲清楚“发生了什么” | 掌握 LOCK 系统/八步法/冲击结局 | 物理线索驱动逻辑 | 结构内化，自然流淌 |
| **精准表达力** | 写出通顺可读的句子 | 识别冗余，学习精准替代 | 繁简两向风格训练 | 形成个人表达风格 |
| **创意生成力** | 确立LOCK四要素（故事核心卡） | 八步法大纲展开 | 七要素质量自评 | 独立完整构思创作 |

### 十二、能力进阶路径（三层境界 → 四阶段）

| 阶段 | 对应境界 | 核心训练目标 | 训练核心动作 | 输出形式 | 典型训练次数 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Lv.0-1 新手** | 见山是山（前期） | 让用户写得出来 | 模仿 + 完成 + 尝试具体化 | 能完成一个完整的描写/场景/故事 | 5-10 次 |
| **Lv.2-3 进阶** | 见山不是山 | 让用户知道有无数种写法 | 分析 + 再创作 | 能写出几种不同技法的版本 | 15-30 次 |
| **Lv.4-5 专业** | 见山不是山（后期） | 让用户融会贯通 | 综合创作 + 七要素自评 | 能在一篇作品中自然运用多种技法 | 30-60 次 |
| **Lv.6+ 大师** | 见山还是山 | 让文字自然流淌 | 释放 | 写出看似直白但直触人心的文字 | 持续精进 |

**各阶段训练难度曲线原理**：

| 阶段 | 难度特征 | 说明 |
| :--- | :--- | :--- |
| **Lv.0-1 新手** | 门槛最低 | 仅需 5-10 次训练即可通关。目标是让用户体验“写完了”的成就感，建立基础信心。Lv.0-1 从“允许直白”调整为“鼓励尝试具体化”，通过引导式填空训练降低门槛。 |
| **Lv.2-3 进阶** | 首次跃升 | 首次引入技法规则约束，难度跃升。用户在此阶段可能“越写越绕”——这是扩展武器库的正常过程，而非退步。 |
| **Lv.4-5 专业** | 继续提升 | 技法综合运用，难度继续提升。目标是让多种技法在作品中协同工作，形成合力。 |
| **Lv.6+ 大师** | 最高境界 | 需要大量创作实践（通常 100+ 次训练），目标是让技巧内化为本能，文字自然流出。 |

**关键提示**：每个阶段之间的训练量并非线性增长，而是逐渐加大。Lv.0-1 到 Lv.2-3 可能只需 2-3 周，Lv.4-5 到 Lv.6+ 可能需要半年以上。这是正常的写作能力成长规律。


## 第四卷：训练内容设计


### 十三、题目体系

#### 13.1 题目分类结构

```
专项能力（5 个）
├── 感官编码力 → 按感官通道分类（视觉/听觉/触觉/嗅觉/味觉/综合）
├── 情绪传递力 → 按情绪种类分类（羞耻/愤怒/悲伤/恐惧/喜悦/爱/厌恶/惊讶/复合情绪）
├── 逻辑编织力 → 按叙事结构分类（线性/环形/多线并行/嵌套）
├── 精准表达力 → 按表达方向分类（极简方向/繁复方向/综合压缩）
└── 创意生成力 → 按构思环节分类（LOCK四要素/八步法大纲/七要素自评/完整创作）
```

#### 13.2 完整题目数据结构

```yaml
题目ID: EMO-SHAME-001
专项: 情绪传递力
情绪分类: 羞耻
子分类: 职场羞辱
灵魂场景: |
  深夜便利店，一个穿西装的中年男人在买烟。
  他刚被公司辞退，不想让任何人知道。
  收银员认出了他，说：“王总，好久不见啊。”
设计意图: |
  这是一个“熟人撞见落魄时刻”的高戏剧冲突场景。
  训练用户在不直接说情绪的前提下，让读者感受到“羞耻”。

对应七要素: 场景、情绪传递

关联知识库词条（观察提示卡）:
  - 观察提示 > 紧张时喉部和手部的变化
  - 观察提示 > 人在羞耻时的身体反应
  - 常见陷阱 > 心理词滥用

经典参照库（仅 Lv.4+ 引入）:
  - 参照ID: REF-001
    风格标签: 海明威式 / 极简 / 动作密集
    片段: "男人端着酒杯，望着远处的山..."
    技法标注: 情绪隐藏在动作和对话之间

难度曲线:
  Lv.0-1: 训练要求 | 评价标准 | 参照匹配（无，仅做规则检测）
  Lv.2-3: 训练要求 | 评价标准 | 参照匹配（无，仅做规则检测+通顺度检测）
  Lv.4-5: 训练要求 | 评价标准 | 参照匹配（2-3 个，多风格对比）
  Lv.6+: 训练要求 | 评价标准 | 参照匹配（无，仅做风格倾向分析）
```

#### 13.3 专项训练具体方法（基于用户自学计划整合）

以下训练方法整合自资深写作者的自我训练方案，已纳入产品各专项的Lv.0-3阶段：

| 专项 | 训练方法 | 说明 |
| :--- | :--- | :--- |
| **感官编码力** | “感官轮盘”练习 | 同一场景强制先后用五种感官各写一遍（5×100字），最后融合成一版完整描写（200字）。让用户理解不同感官通道的独特效果。 |
| **感官编码力** | “五感观察日记” | 每日选择一处场景，用全部五种感官记录细节。作为每日微训练，培养观察习惯。 |
| **情绪传递力** | “对话录音-转写-改写” | 录制一段真实对话，逐字转写，再改写成小说对话，要求每句话背后都隐含未言明的情绪或动机。此训练的目标是让用户理解真实口语节奏与小说对话的差异，而非直接照搬真实对话。 |
| **情绪传递力** | “潜台词改写” | 将一段直白对话（如“我很生气”）改写成含潜台词的版本，让情绪隐藏在字里行间。 |
| **逻辑编织力** | “冲击结局打磨” | 针对故事高潮部分，写出3个不同版本的结局，测试哪种冲击力最强。 |
| **逻辑编织力** | “八步法填空” | 给定一个故事片段，判断它属于八步法的哪一步，练习结构识别能力。 |
| **创意生成力** | “LOCK填空” | 给定一个故事框架，填入主角、目标、冲突、结局四要素，建立故事核心。 |
| **精准表达力** | “多版本改写” | 同一场景写3个风格版本（极简/适中/繁复），对比效果差异。 |

#### 13.4 Lv.0-1 引导式填空训练

Lv.0-1 阶段采用“引导式填空”模式，降低创作门槛的同时训练观察能力：

**【训练题目示例】**
> 给定场景：他得知自己落选了，很失落。
>
> 请完成以下填空：
> 他得知落选的消息，感觉心里______（请填入一个具体的感觉，如“像塞了一团湿棉花”）。
> 他______（请填入一个具体的动作，如“把手机屏幕朝下扣在桌上”），
> 然后______（请填入一个具体的动作，如“盯着窗外的雨发了很久的呆”）。

**设计价值**：填空式任务降低了“从零开始”的心理门槛，同时训练用户将抽象情绪转化为具体观察的能力。

#### 13.5 题目来源（三源整合）

| 来源 | 占比 | 核心价值 | 质量保障 |
| :--- | :--- | :--- | :--- |
| **人工严选（种子题库）** | ≥60% | 质量锚点、人性张力 | 产品团队+签约教练设计 |
| **AI 生成扩展** | ≤40% | 变体扩展 | 基于种子题生成 + 人工抽检 |
| **用户贡献** | 补充 | 多样性、参与感 | AI 初审 + 见习读者复审 |

### 十四、整合训练设计

#### 14.1 核心逻辑

写作能力不是零件能力的简单相加，而是“整体涌现”的结果。训练结构必须兼顾零件与整车：

| 训练类型 | 占比 | 内容 | 目的 |
| :--- | :--- | :--- | :--- |
| **专项训练（零件）** | 60% | 五力各专项拆解训练 | 掌握单项技能 |
| **整合训练（整车）** | 40% | 完整微故事/短篇创作 | 把零件组装成完整作品 |

#### 14.2 项目制训练流程

取消“3次专项+1次微故事”的强制切换，改为**项目制引导**：

```
用户设定“微故事目标”（如“本周写一个含冲突的对话场景”）
         ↓
AI 推荐相关专项训练（围绕该目标所需的技能）
         ↓
用户完成专项训练 → 自动积累到项目中
         ↓
用户自主决定何时进入整合创作
         ↓
完成微故事 → 获得项目完成度评价
```

**项目制启动标准流程**：

```
第一步：确立 LOCK 四要素（故事核心卡）
       ↓
第二步：展开八步法（故事大纲）
       舒适区 → 渴望 → 进入陌生环境 → 适应 → 得到所求 → 付出代价 → 返回原环境 → 角色改变
       ↓
第三步：专项技能填充（关键场景描写）
       ↓
第四步：七要素自评（对照七要素标准自我检查）
       ↓
第五步：完整创作（成文）
       ↓
第六步：AI 评价与修改
```

#### 14.3 整合训练阶段设计

| 阶段 | 专项训练重点 | 整合训练 | 输出作品规模 | 七要素要求 |
| :--- | :--- | :--- | :--- | :--- |
| Lv.0-1 | 感官/情绪/四要素基础 | 完成 3 个完整微故事 | 200-500 字/个 | 情节可识别、人物可区分 |
| Lv.2-3 | 五力技法扩展 | 完成 2 个完整短篇 | 800-1500 字/个 | 结构完整、场景有画面感 |
| Lv.4-5 | 多技法综合应用 | 完成 1 个完整中篇 | 3000-5000 字 | 七要素全面达标 |
| Lv.6+ | 自由创作 | 持续创作 | 长篇或短篇集 | 七要素融合贯通 |


## 第五卷：知识库设计


### 十五、知识库概述

知识库是贯穿训练全流程的**“智能教学引擎”**，而非静态的词汇表。

| 旧定位 | 新定位 |
| :--- | :--- |
| 用户自主查阅的参考材料 | 贯穿训练全流程的“智能教学助手” |
| 独立模块 | 与题目、训练、评价、画像、公用经验库深度联动 |
| 一次建设，长期不变 | 随用户数据和使用反馈持续进化 |

**核心原则**：知识库不应提供“标准答案”，而应提供“观察视角”。不是给词条“吞咽”，而是给提示“观察人在紧张时，喉部和手部会有什么不自觉的动作？”目的是**启发观察**，而非**提供答案**。

### 十六、知识库分类结构

#### 16.1 语料素材库分类

| 语料库名称 | 对应专项 | 内容说明（观察提示卡形式） |
| :--- | :--- | :--- |
| **感官观察提示卡** | 感官编码力 | 按五感分类的观察提示：关注哪些视觉/听觉/触觉/嗅觉/味觉细节 |
| **行为观察提示卡** | 情绪传递力 | 不同情绪下人的身体反应观察提示 |
| **结构模型库** | 逻辑编织力 | LOCK机制、八步故事法、三幕剧、英雄之旅等结构模型说明 |
| **表达风格库** | 精准表达力 | 极简/繁复两种风格的范例对比，而非固定词条 |
| **构思案例库** | 创意生成力 | 经典作品LOCK拆解、八步法范例、七要素分析模板 |
| **七要素参考库** | 综合 | 七要素的定义、合格标准、进阶标准、自评工具 |

#### 16.2 知识库三层结构

| 层级 | 内容 | 作用 |
| :--- | :--- | :--- |
| **见山是山（直接表达层）** | 经典直接表达范例，情感与身体反应的直接映射 | 建立“能写出来”的基础认知 |
| **见山不是山（技巧解构层）** | 行为折射观察提示、感官观察提示、多版本对比 | 扩展“观察视角”而非“词汇列表” |
| **见山还是山（内化回归层）** | 大师级高效表达范例、风格化特征库 | 培养“写出合格作品”的能力 |

#### 16.3 观察提示卡示例

| 传统“词典”方式（易僵化） | **观察提示卡方式（启发观察）** |
| :--- | :--- |
| 紧张→吞咽、目光漂移、手抖 | 观察提示：人在紧张时，喉部会发生什么变化？手部会有什么不自觉的动作？目光会看向哪里？ |
| 悲伤→喉咙发紧、眼眶发热 | 观察提示：人在强忍悲伤时，面部肌肉、呼吸节奏、声音会有什么变化？ |

#### 16.4 七要素分析模板（融入知识库）

知识库中应为每个要素提供“拆解分析模板”，用户可参照分析经典作品或自评作品：

| 要素 | 分析问题 |
| :--- | :--- |
| **情节** | 故事的主要事件是什么？转折点在哪里？高潮是否有力？ |
| **结构** | 故事的开端、发展、结局如何划分？中段是否有拖沓？ |
| **人物** | 主角的目标和动机是否清晰？次要角色是否立体？ |
| **场景** | 读者能否“看见”场景？调动了哪些感官？ |
| **对话** | 对话是否能区分人物？是否有潜台词？ |
| **风格** | 叙事视角是否统一？语言是否有辨识度？ |
| **意义（主题）** | 故事想表达什么核心思想？读者能否理解？ |

#### 16.5 知识库来源与质量标准

- **冷启动**：从经典名篇中提取，不低于 500 个标注样本
- **持续扩充**：用户贡献（经审核）、公用经验沉淀
- **质量标准**：AI 初筛 + 见习读者二审

### 十七、知识库与各模块关联

#### 17.1 知识库 ← → 题目体系

| 关联方向 | 具体机制 |
| :--- | :--- |
| **知识库→题目** | 每个题目的“经典参照”直接从知识库匹配；题目生成时，AI 从知识库中提取对应的观察提示卡作为约束 |
| **题目→知识库** | 用户完成题目后，优秀回答可反向沉淀为知识库新素材（经审核后入库） |

#### 17.2 知识库 ← → 专项训练流程

| 训练环节 | 知识库介入方式 |
| :--- | :--- |
| **训练前** | 系统根据当前专项和等级，自动预加载对应的“观察提示卡”或“七要素模板” |
| **训练中** | 用户可随时点击“查看观察提示”按需查阅；若停留超过 60 秒，系统主动推送相关提示 |
| **训练后** | AI 评价中引用的建议直接链接到知识库具体提示卡 |

#### 17.3 知识库 ← → AI 评价

| 评价环节 | 知识库介入方式 |
| :--- | :--- |
| **规则检测** | 知识库中标注的“心理词列表”作为违规检测依据（仅 Lv.2-3） |
| **观察提示** | 检测到用词单一时，从知识库对应分类中推荐“观察方向”而非“替代词” |
| **七要素参照** | Lv.4-5 阶段，参照七要素标准提供质量反馈 |

#### 17.4 知识库 ← → 用户画像

| 采集行为 | 沉淀为用户画像数据 | 应用场景 |
| :--- | :--- | :--- |
| 用户高频查阅的观察提示分类 | 风格偏好 | 推荐对应风格的参照（仅 Lv.4+） |
| 用户收藏的范例 | 审美倾向 | 新题目生成时倾向匹配同类风格 |
| 用户自评结果 | 弱点分布 | 定向推送对应专项训练 |

#### 17.5 知识库 ← → 公用经验库

| 方向 | 机制 |
| :--- | :--- |
| **知识库→公用经验库** | 知识库中的经典范例作为“权威参照锚点” |
| **公用经验库→知识库** | 高频用户表达经审核后反向扩充到知识库 |


## 第六卷：AI 评价体系


### 十八、评价定位

AI 评价的角色是 **“规则检测器 + 建议生成器”** ，而非“文学评论家”：

- AI 擅长判断“是否遵守了训练规则”
- AI 不擅长判断“写得好不好”
- **Lv.0-3 阶段：仅做规则检测和基础通顺度检测**，不做风格匹配
- **Lv.4+ 阶段：可引入风格参照和七要素参照，但明确标注“仅供参考”**
- 所有评价结果均标注“AI 反馈仅供参考”，保留用户自主判断权

### 十九、评价输入

| 输入 | 内容 |
| :--- | :--- |
| **题目** | 灵魂场景 + 当前等级要求 + 强制规则 |
| **经典参照** | 仅 Lv.4+ 引入，从知识库匹配风格参照 |
| **七要素模板** | Lv.4+ 引入，从知识库匹配七要素分析模板 |
| **用户回答** | 用户提交的描写文本 |
| **关联知识库** | 从知识库中提取观察提示卡作为评价参考 |

### 二十、评价五步流程（分层设计）

#### Lv.0-3 阶段（简化版）

| 步骤 | 内容 | 输出 |
| :--- | :--- | :--- |
| **第一步：规则检测** | 对照等级要求中的强制规则 | 规则遵守/违反 + 违规词列表 |
| **第二步：通顺度检测** | 检测是否有语病、是否可读 | 基础可读性评分 |
| **第三步：改进建议** | 基于规则检测，从知识库中提取观察方向 | 1-3 条修改方向 |
| **第四步：鼓励反馈** | 肯定用户“写出来了”这件事本身 | 正向激励 |

**此阶段不做：** 风格匹配、独特性判断、与经典参照对比、七要素评判

#### Lv.4+ 阶段（完整版）

| 步骤 | 内容 | 输出 |
| :--- | :--- | :--- |
| **第一步：规则检测** | 对照等级要求中的强制规则 | 规则遵守/违反 + 违规词列表 |
| **第二步：风格倾向分析** | 分析用户作品风格特征（描述性，非评判性） | 风格标签（仅供用户参考） |
| **第三步：七要素对照** | 从七要素维度分析作品质量 | 七要素雷达图（各维度评分） |
| **第四步：参照对比** | 用户回答 vs 经典参照（仅作为“坐标点”） | 差异分析 |
| **第五步：改进建议** | 基于对照和分析，从知识库中提取建议 | 1-3 条修改方向 |
| **第六步：风格偏离提示** | 当作品与所有参照差异均较大时触发 | “你的写法与参考范例差异较大，请自行判断” |

### 二十一、经典参照匹配策略

| 等级 | 参照数量 | 参照来源 | 评价侧重 |
| :--- | :--- | :--- | :--- |
| **Lv.0-1** | 0 个 | 不引入参照 | 是否能写清楚、情绪是否可识别 |
| **Lv.2-3** | 0 个 | 不引入参照 | 规则遵守 + 基础通顺度 |
| **Lv.4-5** | 2-3 个 | 从知识库匹配多风格参照 | 七要素质量 + 技法多样性 |
| **Lv.6+** | 0 个 | 无参照，仅做风格倾向分析 | 可朗读性 + 读者触动度 |

### 二十二、评价输出示例

#### Lv.2-3 评价示例

```
📊 你的评价报告

【规则检测】
✅ 心理词归零：通过
✅ 行为词数量：3 个（达标）
✅ 基础通顺度：可读

【改进建议】
1. “目光偏移”和“喉结滑动”都在传递“回避”。建议合二为一，用一个更具体的动作来表达。
2. 节奏方面：你的句子偏长，建议将其中一句拆短，制造紧张感。

【观察提示】
📚 试试观察：人在感到羞耻时，除了喉部和手部，肩膀和呼吸节奏会有什么变化？
→ 知识库相关提示卡：羞耻时的身体反应观察

【鼓励反馈】
✨ 你已经能做到在不用心理词的情况下传递基本情绪，这是重要的一步！
✨ 继续保持观察生活的习惯。

【综合评分】
规则遵守率：100/100
综合评分：7/10
```

#### Lv.4-5 评价示例（含七要素对照）

```
📊 你的评价报告

【规则检测】
✅ 心理词归零：通过 | ✅ 行为词数量：4 个

【风格倾向分析】（仅供参考）
你的作品风格倾向：偏向生活流叙事，注重日常细节。

【七要素对照】
| 要素 | 评分 | 说明 |
| :--- | :--- | :--- |
| 情节 | 7/10 | 因果链清晰，但高潮冲击力可加强 |
| 结构 | 8/10 | 八步法完整，中段节奏良好 |
| 人物 | 6/10 | 主角动机清晰，次要角色偏单薄 |
```

## 第七卷：用户反馈与评价修正


### 二十三、用户对 AI 评价的反馈机制

#### 23.1 三种表达方式

| 层级 | 交互方式 | 用途 |
| :--- | :--- | :--- |
| **第一层：一键反馈** | 点赞👍/点踩👎 | 大规模定性数据收集 |
| **第二层：标注明细** | 点击评价中的具体问题点 | 精确定位误判位置 |
| **第三层：补充说明** | 可选文本框 | 深入理解用户意图 |

#### 23.2 反馈合理性判断

| 合理性高的信号 | 合理性低的信号 |
| :--- | :--- |
| 有具体文本锚点 | 笼统说“不对”“不好” |
| 有替代方案 | 仅表达了感受 |
| 与训练规则相关 | 与个人偏好相关 |
| 用户历史信誉高 | 用户历史信誉低 |

### 二十四、数据飞轮

```
① 用户收到 AI 评价
         ↓
② 用户提交反馈（点赞/点踩 + 理由）
         ↓
③ 见习读者验证 → 采纳
         ↓
④ 采纳后的数据沉淀：
   ├── 评价 Prompt 优化（短期）
   ├── 误判模式库（中期）
   ├── 知识库观察提示权重调整（中期）
   ├── 经典参照库扩充（长期）
   └── 用户画像精度提升（实时）
         ↓
⑤ 优化后的评价系统 → 服务下一批用户
```

### 二十五、评价系统冷启动策略

| 阶段 | 评价系统状态 | 核心策略 |
| :--- | :--- | :--- |
| **V1.0-V1.5** | 不追求完美，以规则检测为主 | AI 评价以“规则提醒”为主；明确提示“AI 反馈仅供参考”；通过深度访谈收集 50-100 名种子用户的真实反馈 |
| **V2.0+** | 逐步引入复杂评价 | 基于累积的标注数据，逐步优化评价系统 |

## 第九卷：社区设计


### 三十、社区定位

**社区是“共鸣空间”，不是“竞技场”** 。
- 核心功能：让用户看到“别人也在死磕”，缓解孤独感
- 不设公开排行榜
- 不设竞技元素

### 三十一、共修训练营

- 按“攻克同一弱点”分组（如“对话潜台词特训营”）
- 组内分享：修改心得、卡壳经历、突破时刻
- 不比拼分数，比拼“死磕精神”
- 可围绕“七要素”组织专项共修小组（如“场景描写共修营”、“人物塑造共修营”）

### 三十二、匿名读者团（V1.0 由 AI 模拟）

| 原设计 | 修改后 |
| :--- | :--- |
| 见习裁判评分 | 匿名读者团仅提供感受标签 |
| 评价他人作品 | 仅标注“这段让我感到……” |
| 可能产生偏见和圈层 | 匿名化、无评分、无投票 |
| 依赖社区活跃度 | **V1.0 由 AI 模拟读者感受，不依赖真人社区** |
