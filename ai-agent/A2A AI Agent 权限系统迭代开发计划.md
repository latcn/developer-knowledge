# A2A AI Agent 对话式权限系统 - 迭代开发计划

---

## 一、项目概述

本计划基于架构设计文档和技术分析，旨在分阶段实现 A2A AI Agent 对话式权限系统的核心功能。

### 整体时间规划：12 周

---

## 二、Phase 1：核心基础设施搭建（第 1-2 周）

**目标**：完成授权服务器和基础认证能力

| 序号 | 任务 | 描述 | 验收标准 |
|------|------|------|---------|
| 1.1 | OAuth2 授权服务器配置 | 完成 Spring Authorization Server 完整配置 | Spring Authorization Server 正常启动，支持 Token Exchange |
| 1.2 | JWT ES256 签名服务 | 实现 ES256 椭圆曲线签名 | 生成有效的 ES256 签名 JWT，支持 JWKS 端点 |
| 1.3 | Token Exchange 功能 | 完善 Token Exchange 端点实现 | 正确校验 ACL 白名单，填充 `allowed_permission_ids` |
| 1.4 | 数据库初始化 | 执行数据库 DDL 脚本 | 验证所有表创建成功 |

**关键输出**：
- 授权服务器可正常签发 JWT
- Token Exchange 端点支持代理授权

---

## 三、Phase 2：权限核心功能（第 3-4 周）

**目标**：完成权限校验和行级规则注入能力

| 序号 | 任务 | 描述 | 验收标准 |
|------|------|------|---------|
| 2.1 | SQL 行级规则注入拦截器 | 使用 JSqlParser 实现 SQL 条件注入 | 正确解析并注入 WHERE 条件 |
| 2.2 | 角色权限服务 | 完善权限查询和校验逻辑 | 支持用户权限查询、批量权限获取 |
| 2.3 | 责任链权限校验 | 完善责任链处理器协作 | RolePermissionHandler 和 IntentRiskHandler 正常工作 |
| 2.4 | 用户属性二级缓存 | 实现 Caffeine + Redis 缓存策略 | 缓存命中和降级机制生效 |

**关键输出**：
- SQL 查询自动注入行级过滤条件
- 用户属性支持多级缓存降级

---

## 四、Phase 3：安全与风控功能（第 5-6 周）

**目标**：完成异步确认模式和安全防护能力

| 序号 | 任务 | 描述 | 验收标准 |
|------|------|------|---------|
| 3.1 | 异步确认模式 | Redis 暂存加密数据，HTTP 回调确认 | 完整的人工确认流程 |
| 3.2 | 数据加密签名服务 | AES-GCM 加密 + ES256 签名 | 数据存储和验证完整实现 |
| 3.3 | 滑动窗口限流 | Redis ZSET 限流实现 | 支持 Agent/用户/工具级别限流 |
| 3.4 | 断路器集成 | Resilience4j 熔断降级 | Redis 不可用时降级到本地缓存 |

**关键输出**：
- 高风险操作自动触发人工确认流程
- 限流和熔断保护机制生效

---

| 4.4 | 性能优化与压测                  | 调优配置，性能测试             | 单机并发达到 1000+ QPS |

**关键输出**：
